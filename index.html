Política de privacidad

Última actualización: 24 de noviembre de 2026.

1. Responsable

Shorts Hub es una herramienta privada de análisis de estadísticas de redes sociales, desarrollada para uso personal.

Contacto: eduardo.araujo.iglesias@gmail.com

2. Información que se consulta

La aplicación puede acceder, previa autorización del titular de las cuentas, a información de YouTube, Instagram y TikTok, incluyendo:

  • Información básica del perfil y del canal.
  • Visualizaciones y estadísticas de publicaciones.
  • Interacciones, como me gusta, comentarios y compartidos.
  • Información estadística y de rendimiento disponible a través de las API oficiales.

3. Finalidad del tratamiento

Los datos se utilizan exclusivamente para mostrar, organizar y comparar estadísticas de rendimiento de las cuentas conectadas dentro de Shorts Hub.

4. Almacenamiento y seguridad

En la versión privada actual, la aplicación funciona en el equipo del usuario. Las credenciales y tokens de acceso se almacenan localmente y deben mantenerse protegidos.

Los datos solicitados a las plataformas se transmiten a través de sus respectivas API oficiales. No se venden ni se comercializan los datos personales.

5. Servicios de terceros

Shorts Hub utiliza las API oficiales de Google/YouTube, Meta/Instagram y TikTok. El acceso está sujeto a los permisos concedidos por el usuario y a las políticas de privacidad de cada plataforma.

6. Revocación del acceso

El usuario puede retirar los permisos concedidos a Shorts Hub desde la configuración de aplicaciones conectadas de cada plataforma. También puede eliminar los tokens almacenados localmente.

7. Conservación y eliminación

La información se conserva localmente mientras sea necesaria para el funcionamiento de la aplicación. El usuario puede eliminar los archivos locales correspondientes.

8. Cambios en esta política

Esta política podrá actualizarse cuando cambien las funciones o el tratamiento de datos de Shorts Hub.

Términos del servicio

Última actualización: 24 de noviembre de 2026.

1. Descripción

Shorts Hub es una herramienta privada diseñada para consultar y comparar estadísticas de contenido publicado en distintas redes sociales.

2. Uso autorizado

El usuario solo debe conectar cuentas propias o aquellas para las que disponga de autorización expresa.

3. Servicios externos

La conexión con YouTube, Instagram y TikTok depende de sus respectivas API, permisos, disponibilidad y condiciones de uso. Shorts Hub no controla esos servicios ni garantiza su disponibilidad permanente.

4. Uso de los datos

Las estadísticas se muestran con fines informativos y de análisis. Su disponibilidad y precisión dependen de la información proporcionada por cada plataforma.

5. Responsabilidad

El usuario es responsable de proteger sus credenciales y tokens de acceso, así como de cumplir las condiciones de uso de las plataformas conectadas.

6. Modificaciones

Las funcionalidades y estos términos podrán modificarse cuando sea necesario.

7. Contacto

Para cualquier consulta sobre Shorts Hub, utiliza el correo electrónico de contacto indicado en la política de privacidad.
